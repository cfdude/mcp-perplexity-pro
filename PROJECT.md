- `py-search-api` (P1, openspec, planned) — Search API tool with full filter set — POST /search: multi-query, dates (MM/DD/YYYY), language, domain allow/deny, recency, country, max_tokens, search_type web|fast|people. Structured JSON results. Resolve page-snippets endpoint if one is documented.
- `model-routing` (P2, openspec, later) — Model routing: pick cheapest adequate model per request — Parent epic for routing. Own decision matrix chooses preset/model per prompt; escalates on complexity; optionally uses Perplexity Decisions API as classifier. Not in 2.0 (2.0 ships explicit depth param). Savings target unverified; measured in routing-eval-tuning.
- `py-decisions-tool` (P2, openspec, planned) — Decisions API tool (decide) — Thin wrapper over POST /v1/decisions (noul/choice/score questions), question-count cap, no image support in v1.
- `py-embeddings` (P2, openspec, planned) — Embeddings tool with local vector store and semantic search — pplx-embed models, base64 int8/binary decode, local storage, semantic search over saved chats/reports. Never return raw vectors to the model.
- `routing-rules-v1` (P2, openspec, later) — Deterministic complexity matrix selects preset (depth=auto) — Rules-based classifier (prompt length, task type, tool needs) picking fast/low/medium/high; runs only when depth=auto.
- `routing-decisions-classifier` (P3, openspec, later) — Use Perplexity Decisions API as routing classifier — Send prompt as state with choice/score questions about complexity; $0.02/1M tokens; adds one network hop and is rate-limited to 10 req/s per org.
- `routing-escalation` (P3, openspec, later) — Escalate to higher tier on incomplete or low-confidence result — Retry one tier up when status is incomplete or classifier confidence is low; bounded retries; cost-logged.
- `routing-eval-tuning` (P3, openspec, later) — Measure routing savings and quality against always-high baseline — Labeled prompt set plus usage log. The only place a savings number gets claimed. No headline percentage before this runs.
- `routing-router-api-backend` (P3, external, later) — Perplexity Router API as an open-model backend — Private preview, access requested. Routes to open-weight models only. Blocked until access is granted.
